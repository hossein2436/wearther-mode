# Redesign (v4)

Design exploration for Wearther Mode — not yet applied to the main code.

- `v4/REDESIGN.md` — what changed in v4–v4.4 and why (calm editorial theme, flat-lay by default, body-order stack, "Why this look" reasons).
- `v4/wearther-v4.html` — standalone interactive prototype (open in a browser, no build step). All photos are embedded; no network needed.
- `v4/tokens-v4.css` / `v4/app-v4.css` — drop-in replacements for `src/theme/tokens.css` / `src/theme/app.css` when the redesign is applied to the app.
- `v4/PHOTO-SOURCES.md` — where the prototype photos came from and their licences.
